# computer_vision
Este repositorio contiene las prácticas de la asignatura **visión por computador** de la Universidad de Granada en el curso 25/26.

  - **[deep_learning_basics.ipynb](deep_learning_basics.ipynb)**: Entrenamiento de una red neuronal convolucional propuesta por el profesor de la asignatura sobre CIFAR-100 alcanzando 33% de accuracy. Después, uno debe rediseñar la arquitectura de la red para alcanzar un 65% de accuracy.
  - **[fine_tuning.ipynb](fine_tuning.ipynb)**: Transfer Learning. Cambiar la cabecera de ResNet-34 para realizar comparativa de entrenamiento sobre un problema de regresión, basado en predecir la edad a partir de radiografías torácicas [https://www.kaggle.com/competitions/spr-x-ray-age/data](https://www.kaggle.com/competitions/spr-x-ray-age/data). La comparativa en cuestión se basa en primer lugar, de entrenar la red desde 0 (207 MSE ~ 14 años), después tomando pesos preentrenados y haciendo fine tuning solo de la cabecera (115 MSE ~ 11 años) y por último tomando pesos preentrenados entrenando esta vez toda la red (60 MSE ~ 7 años). De este modo, se aprende la ventaja de tomar pesos preentrenados y realizar un segundo entrenamiento adaptado al problema. 
  - **[explainable_ai.ipynb](explainable_ai.ipynb)**: Uso del modelo **EfficientNet-B0** para entrenar el conjunto (https://www.vision.caltech.edu/datasets/cub_200_2011/)[https://www.vision.caltech.edu/datasets/cub_200_2011/] de aves de 200 clases. A continuación, se aplica el algoritmo **grad-CAM** para obtener explicaciones de la predicción del modelo. Los mapas de calor resultantes del algoritmo muestran los elementos en los que se fijan los modelos para obtener sus predicciones (p.e. el color rojo singular de una especie recibe especial atención por parte del modelo para su clasificación).
  - **[img_filtering.ipynb](img_filtering.ipynb)**: Fundamentos del filtrado gaussiano. Pirámides Guassianas y de Laplace. Imágenes híbridas. Detección de bordes en imágenes con Canny Edge Detector.
  - **[keypoint_matching.ipynb](keypoint_matching.ipynb)**: Detección de corners. Keypoint Matching para emparejar puntos de dos imágenes del mismo paisaje utilizando diferentes perspectivas.
